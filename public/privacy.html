Privacy & Data Use

This is a hackathon prototype built for Smart India Hackathon 2026. It is not an official Government of India service, and no real applicant data should be entered into this demo instance.

What's stored

Officer accounts (name, officer code, branch, a hashed password) and submitted applications (business and cash-flow details, the identity/fraud signals entered by the officer, and the generated scores and decisions) are stored in a Firestore database associated with this deployment.

Who can see it

Only authenticated officers, through this application's API — there is no public or client-side access to the underlying database. All decline decisions carry the name of the officer who made them, for audit purposes.

Sensitive identifiers

The "Applicant ID / Phone Reference" field exists only to detect repeat applications from the same identity across the system. For this demo, do not enter real Aadhaar, PAN, or other government ID numbers — use a placeholder reference instead.

Contact

Questions about this prototype can be directed to the project team listed in the Smart India Hackathon 2026 submission materials.
